## 🚀 Quick Start with Python

Run the complete interactive creative universe locally using the built-in Python server (zero external dependencies required):

```bash
# Clone the repository
git clone https://github.com/lokeshkumar143/teddy_bear.git
cd teddy_bear

# Start the Python Universe server
python3 app.py

# Or launch directly into your browser:
python3 app.py --open
```

The server automatically selects an available port (`http://localhost:8000`), configures modern MIME types, and exposes diagnostic API endpoints:
- `http://localhost:8000/api/status` — Server health, uptime, and telemetry
- `http://localhost:8000/api/universe-info` — Generative math and cosmic dimension metadata

## 🌌 The 10-Stage Cinematic Experience

1. **Scene 1: Cosmic Void** — Midnight space with multi-layered twinkling starfield and ambient nebula.
2. **Scene 2: Narration** — Mysterious typewriter narration welcoming the visitor.
3. **Scene 3: The Invitation** — Softly floating gift box asking before creating.
4. **Scene 4: Name Etching** — Visitor inputs their name to be etched into the stars.
5. **Scene 5: Cherished Memory** — Optional photo upload framed in a vintage Polaroid keepsake.
6. **Scene 6: Star-Forging Bloom** — Procedural bloom weaving plush ASCII fur from cosmic stardust.
7. **Scene 7: The Star Bear** — High-precision mathematical Signed Distance Field (SDF) ASCII bear.
8. **Scene 8: Radiant Beating Heart** — Cardioid chest heart pulsing with custom embroidered name badge.
9. **Scene 9: The Gift** — Interactive waving, audio chimes, and high-resolution PNG snapshot download.
10. **Scene 10: Multiverse Portal** — High-speed dimensional warp transition to Lokesh's Creative Multiverse.

## 🛠️ Clean Architecture

```text
├── app.py                      # Python threaded server & API hub
├── index.html                  # Accessible semantic entry point (v9.0)
├── main.js                     # 60 FPS master animation loop & lifecycle
├── teddyExperience.css         # Glassmorphism, safe-areas & responsive CSS
├── teddyExperienceController.js# 10-stage state machine
├── teddyAsciiRenderer.js       # 70x68 SDF ASCII synthesis & canvas renderer
├── teddyGeometry.js            # Signed distance fields & cardioid heart math
├── teddyCharacterParts.js      # Anatomical glyph density ramps & palette maps
├── teddyCharacterAnimation.js  # Breathing, blinking, gazing & waving physics
├── teddyLighting.js            # 3D normal hemisphere lighting
├── teddyParticleWorld.js       # Starfield, shooting stars & Web Audio synthesizer
├── teddyIntroScene.js          # Converging stars & typewriter narration
├── teddyInvitation.js          # Interactive invitation dialog
├── teddyPersonalization.js     # Name entry & client-side photo handler
├── teddyGiftReveal.js          # Gift presentation dialog & snapshot export
├── art.py                      # Python ASCII animation renderer (Pillow/imageio)
└── art.mp4                     # Rendered 1080x1920 ASCII showcase video
```
